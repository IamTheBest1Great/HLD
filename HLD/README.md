# HLD Consolidated Notes — File Guide

This pack consolidates the uploaded HLD notes into five purpose-based Markdown files.

## Files

1. **01_HLD_Architecture_and_Interview_Framework.md**
   - Universal HLD architecture mental model
   - 6-step interview framework
   - Component placement and connection rules
   - Decision trees, archetypes, trade-offs, anti-patterns
   - Visual architecture process and generic implementation template

2. **02_HLD_Foundations_and_Core_Concepts.md**
   - What HLD interviews evaluate
   - Networking, scaling, databases, caching, queues, storage
   - Reliability, CAP/PACELC and distributed-systems foundations
   - Compact supporting roadmap material

3. **03_HLD_Patterns_and_Practice_Problems.md**
   - Complete system-design patterns and deep dives
   - Pattern-to-problem mapping
   - Master practice question maps

4. **04_HLD_Learning_Roadmap_Execution_and_Tracking.md**
   - 120-day and shorter mastery roadmaps
   - Learning order, execution plans, tracking templates
   - Advanced topics, resources, checklists, and interview practice

5. **05_Social_Media_System_Design_Syllabus.md**
   - Social-media system design course/topic structure
   - Requirements, capacity, database/API design, feeds, media, scaling, and trade-offs

## Consolidation Method

- Content was reorganized by purpose rather than preserving the original overlapping file boundaries.
- Exact duplicate content blocks were removed across the consolidated pack.
- Non-identical explanations were retained because they may contain complementary details.
- The original files are not modified or deleted by this generated pack.
